# Contributing

Contributions that make the playbook clearer, more testable, or more useful across vendors are welcome.

## Good contributions

- Add a concrete decision criterion or evidence requirement.
- Clarify ownership, failure modes, or exit conditions.
- Improve accessibility, structure, or plain-language guidance.
- Correct a technical error with a primary source when relevant.

## Keep changes safe

- Do not include secrets, personal data, customer names, private endpoints, or internal project details.
- Do not present vendor claims as independently validated facts.
- Do not add unlicensed third-party text or proprietary assessment content.
- Keep examples synthetic and vendor-neutral.

## Pull requests

Describe the decision problem, the proposed change, and how a reviewer can judge whether it improves the framework. Small, coherent changes are easier to review than broad rewrites.
