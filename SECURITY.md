# Security policy

## Reporting a problem

Do not open a public issue containing credentials, personal data, customer information, private architecture details, or an unpatched vulnerability in a deployed system.

For problems in these documents, open a minimal issue that describes the affected file and the class of concern without sensitive details. If safe public disclosure is not possible, do not submit the sensitive material to this repository.

## Scope

This repository contains documentation and templates only. It does not provide a hosted service, model, runtime, security control, or warranty. Examples are intentionally generic and must be adapted to local policies and threat models.

## Safe use

- Never paste live secrets or regulated data into templates.
- Use placeholders for identities, endpoints, customers, and internal systems.
- Store completed assessments in an approved access-controlled system.
- Validate all controls in the target environment.
- Escalate suspected exposure through your organization’s incident process.
